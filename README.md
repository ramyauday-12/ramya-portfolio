# Ramya Udayakumar: Portfolio

Static site with no build step, ready for GitHub Pages. Replace the repo contents with this folder.

- `index.html`: page, styles and the animation code
- `assets/js/projects.js`: all projects (featured cards, gallery, filters and detail popups). Edit here to add or change a project.
- `assets/img/`: project screenshots (WebP, about 1400px wide). Add `images: [{ src, alt, caption, w, h }]` to a project in projects.js.
- `assets/resume/Ramya_Udayakumar_Resume.pdf`: the resume (replace the file, keep the name)
- `assets/clips/c1-c5.webp`: the character animation, five clips packed as WebP frames that scrolling drives

Libraries (GSAP, ScrollTrigger, Lenis, Matter.js) and fonts load from public CDNs.
